# marksapi
A CLI application covering access to 

- Unified application: Central point for interacting with an array of API
- Configurable: Configurable logging provider via **Serilog**

## Getting started

Generally, the [marksapi cli tool](./src/cli/marksapi/README.md) is used. See the [installation](./src/cli/marksapi/README.md#installation) section for build details.

### Note
This project contains an unofficial client application for the **Massive** market data API. [Official client libraries](https://massive.com/docs/rest/quickstart#explore-client-libraries) are available, and are expected to cover more features and receive faster updates.
