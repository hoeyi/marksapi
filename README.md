# Markets Nexus API
The Markets Nexus API is a library containing lightweight API clients for consuming different commerical and non-commerical APIs covering economic and market data.


- CLR Interface: Consistent methods for retrieving quotes (OHLC), price series, and company or fund metadata across supported APIs.
- Configurable: Easy setup of API keys.
