# marksapi
A CLI application covering access to financial market and economic APIs.

## Getting started

Generally, the [marksapi cli tool](./src/cli/README.md) is used. See the [installation](./src/cli/README.md#installation) section for build details.

### Note
This project contains an unofficial client application for the **Massive** market data API. [Official client libraries](https://massive.com/docs/rest/quickstart#explore-client-libraries) are available, and are expected to cover more features and receive faster updates.
